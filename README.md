## 环境要求

- macOS + Xcode（含 Command Line Tools）
- Git，SSH 方式访问 GitHub

## 快速开始

```bash
git clone git@github.com:anzihenry/dsh-biucing-apple-dev.git
cd dsh-biucing-apple-dev
```
